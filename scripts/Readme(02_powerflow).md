1) Problem Description and Technical Background

1.1) The Power Network
This workshop uses a custom 5-bus radial distribution feeder built with pandapower. The network has the following structure:

Bus 0 (Slack / External Grid)  — voltage fixed at 1.0 pu, angle fixed at 0 degrees
  |
Bus 1 (PQ Load bus)            — consumes active power P1 and reactive power Q1
  |
Bus 2 (PQ Load bus)            — consumes active power P2 and reactive power Q2
 / \
Bus 3 (Solar PV — sgen)        — injects P_solar and Q_solar
Bus 4 (PQ Load bus)            — consumes active power P4 and reactive power Q4

All buses operate at a nominal voltage of 20 kV. Lines use typical medium-voltage overhead parameters (r = 0.642 ohm/km, x = 0.083 ohm/km). The slack bus (Bus 0) represents the connection to the external transmission grid and holds voltage constant at 1.0 per unit.
-----------------------------------------------------------------------------------------------------
1.2) The Power Flow Problem
Given the power consumed and injected at every bus, AC power flow analysis solves for the voltage magnitude |V| and angle delta at every non-slack bus. This requires solving a nonlinear system of equations iteratively using Newton-Raphson or similar methods. pandapower handles this numerically.

The standard AC power flow equations at each bus i are:

P_i = |V_i| * SUM_k [ |V_k| * (G_ik * cos(delta_i - delta_k) + B_ik * sin(delta_i - delta_k)) ]
Q_i = |V_i| * SUM_k [ |V_k| * (G_ik * sin(delta_i - delta_k) - B_ik * cos(delta_i - delta_k)) ]

where G and B are the real and imaginary parts of the Y-bus admittance matrix, which encodes the network topology and line impedances.
-----------------------------------------------------------------------------------------------------

1.3) What the Surrogate Learns
The surrogate model learns the mapping from known quantities to unknown quantities in the standard power flow formulation.

2) MOdels

2.1) Pure MLP Surrogate
The first model is a standard multilayer perceptron (MLP) trained with mean squared error (MSE) loss on (input, output) pairs generated by pandapower:

Architecture: Input(8) -> Linear(128) -> BatchNorm -> ReLU
                       -> Linear(128) -> BatchNorm -> ReLU
                       -> Linear(64)  -> BatchNorm -> ReLU
                       -> Linear(8)   -> Output

BatchNorm layers are included because input features (MW, MVAr) and output features (pu voltages, degrees) are on very different numerical scales. BatchNorm stabilises training by normalising activations within each batch.

Total trainable parameters: approximately 27,657. Training uses Adam optimiser with learning rate 0.001, batch size 256, and ReduceLROnPlateau scheduler. Two checkpoints are saved: a starting-point model at 20 epochs and a fully trained instructor model at 200 epochs.

-----------------------------------------------------------------------------------------------------

2.2) Physics-Informed Neural Network (PINN)
The PINN uses the identical architecture as the pure MLP. The only difference is the training loss function, which combines a data-driven term and a physics residual term:

L_total = L_data + lambda * L_physics

L_data    = MSE(y_pred_scaled, y_true_scaled)
L_physics = mean squared power balance residual across all non-slack buses
lambda    = 0.1  (physics weight, tuned for this network)

5) Key Results and Observation

5.1) In-Distribution Performance (on training data):
Both MLP and PINN achieve near-identical performance within the training range (load ±20%). The surrogate approximates pandapower results to high accuracy:
•	Voltage magnitude MAE: approximately 0.00001 to 0.00003 pu
•	Voltage angle MAE: approximately 0.0003 to 0.0009 degrees
This confirms that 5000 training samples and the chosen MLP architecture are sufficient for this 5-bus network within the training distribution.

5.2) 8.2 Out-of-Distribution Performance (on testing data):
When tested on load perturbations outside the training range (±40%), both models show increased error. The PINN degrades more slowly:
•	Voltage magnitude error increases by approximately 2 to 2.5x on OOD data
•	PINN reduces physics constraint violation by approximately 42% compared to the pure MLP on OOD data
•	The improvement is more visible on voltage angles than magnitudes, particularly at Bus 3 (Solar)
