## 1. Problem Description and Technical Background

### 1.1 The Power Network

This workshop uses a custom 5-bus radial distribution feeder built with pandapower.

```
Bus 0 (Slack / External Grid)  — voltage fixed at 1.0 pu, angle = 0°
    |
Bus 1 (PQ Load)  — consumes P1, Q1
    |
Bus 2 (PQ Load)  — consumes P2, Q2
   / \
Bus 3 (Solar PV) — injects P_solar, Q_solar
Bus 4 (PQ Load)  — consumes P4, Q4
```

All buses operate at nominal 20 kV. Lines use typical medium-voltage overhead parameters:
- Resistance: r = 0.642 Ω/km
- Reactance: x = 0.083 Ω/km

The slack bus (Bus 0) represents the connection to the external transmission grid and holds voltage constant at 1.0 per unit.

### 1.2 The Power Flow Problem

Given the power consumed and injected at every bus, AC power flow analysis solves for the voltage magnitude |V| and angle δ at every non-slack bus using Newton-Raphson iteration.

The standard AC power flow equations at each bus *i*:

$$P_i = |V_i| \sum_k |V_k| \left( G_{ik} \cos(\delta_i - \delta_k) + B_{ik} \sin(\delta_i - \delta_k) \right)$$

$$Q_i = |V_i| \sum_k |V_k| \left( G_{ik} \sin(\delta_i - \delta_k) - B_{ik} \cos(\delta_i - \delta_k) \right)$$

where G and B are the real and imaginary parts of the Y-bus admittance matrix.

### 1.3 What the Surrogate Learns

The surrogate model learns the mapping:

$$f_\theta : (P_{load}, Q_{load}, P_{solar}) \rightarrow (|V|, \delta, \text{line loading})$$

## 2. Models

### 2.1 Pure MLP Surrogate

Standard multilayer perceptron trained with MSE loss on (input, output) pairs generated by pandapower.

**Architecture:**
```
Input(8) → Linear(128) → BatchNorm → ReLU
         → Linear(128) → BatchNorm → ReLU
         → Linear(64)  → BatchNorm → ReLU
         → Linear(8)   → Output
```

| Parameter | Value |
|---|---|
| Trainable parameters | ~27,657 |
| Optimiser | Adam, lr=0.001 |
| Batch size | 256 |
| Scheduler | ReduceLROnPlateau |

Two checkpoints are saved: a starting-point model at 20 epochs and a fully trained instructor model at 200 epochs.

### 2.2 Physics-Informed Neural Network (PINN)

Identical architecture to the pure MLP. The only difference is the training loss:

$$\mathcal{L}_{total} = \mathcal{L}_{data} + \lambda \cdot \mathcal{L}_{physics}$$

where:
- $\mathcal{L}_{data}$ = MSE on scaled predictions vs. scaled targets
- $\mathcal{L}_{physics}$ = mean squared power balance residual across all non-slack buses
- $\lambda = 0.1$ (physics weight)

### 2.3 Training Data

| Split | Label in CSV | Load range | Samples | Purpose |
|---|---|---|---|---|
| Training | `train` | ±20% of nominal | 5,000 | Model training and validation |
| OOD test | `ood_test` | ±40% of nominal | 1,000 | Out-of-distribution evaluation |

## 5. Key Results

### 5.1 In-Distribution Performance (load ±20%)

Both MLP and PINN achieve near-identical high accuracy within the training range:

| Metric | Value |
|---|---|
| Voltage magnitude MAE | 0.00001 – 0.00003 pu |
| Voltage angle MAE | 0.0003 – 0.0009 degrees |

5,000 training samples and the chosen architecture are sufficient for this 5-bus network within the training distribution.

### 5.2 Out-of-Distribution Performance (load ±40%)

When tested on perturbations outside the training range, both models show increased error. The PINN degrades more slowly:

| Observation | Result |
|---|---|
| Voltage magnitude error increase on OOD data | ~2 – 2.5× |
| PINN physics constraint violation vs. MLP | ~42% lower |
| Most visible improvement | Voltage angles, especially Bus 3 (Solar) |
